## 本轮发现并修复

1. 合成测试页继承了禁止内联脚本的 CSP，导致基线按钮不执行。测试夹具改为同源脚本后重测通过，不将其算作 qpool 权限缺陷。
2. 真实桌面聊天恢复请求带有历史浏览器 `function_call_output`，第一次进入 qpool 时被误拒绝为无绑定续轮。现允许**原生账号已认证、明确指定真实模型、尚无绑定且含原始用户上下文**的恢复请求建立绑定，继续校验账号、模型、目录和额度；输入历史原样保留。自动别名及专用入口仍不能猜测旧工具续轮模型。
3. 桌面会在工具结果后追加 developer/system 元消息。续轮判断现在跳过这些消息，避免仅追加运行时工具目录就把旧续轮当成新任务重新路由。

新测试覆盖明确模型恢复、原输入保留、自动别名拒绝，以及尾部元消息变体下两入口均拒绝。完整回归 164 项通过（75.943 秒）；随后对尾部元消息变体单独回归通过。独立审查复核了账号与模型约束、两入口隔离和并发配置保护。
